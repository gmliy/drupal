## 1. SEO 评分

已完成，已验证。

分数只由 `SeoResult::score()` 按字段检查计算。模型返回的 `seo_score`、问题严重程度、堆砌标记不进入分数。详情页规则首句写明这一点。分析记录里的 `analysis_metadata.score_source` 为 `rules`。

维度和满分：

| 维度 | 满分 | 不适用时 |
| --- | --- | --- |
| SEO 标题 | 20 | 没有标题字段则未检查，不进分母 |
| Meta Description | 20 | 没有描述来源则未检查 |
| 内容完整性 | 20 | 未知内容类型未检查 |
| 关键词相关性 | 15 | 没有标题则未检查 |
| 标签相关性 | 10 | 内容类型没有标签字段则不进分母 |
| 图片 ALT | 10 | 非美图且没有图片则不进分母；美图没有 ALT 记 0 |
| 内部链接 | 5 | 美图、视频不进分母 |

换算：已检查得分 / 已检查满分 × 100，四舍五入。未检查项不记满分。每条规则带原因，例如「标题短于 4 个字」。同一输入重复计算得到同一分数。

内容类型差异：文章正文短于 80 字扣分；基础页正文短于 40 字扣分；美图看简介；视频同时看文字和时长。基础页没有标签和图片时，这两项不进分母。

独立测试：`web/modules/custom/xedc_ai/tests/manual/seo-ops-test.php`。Docker `php:8.3-cli` 隔离运行，不挂数据库。本次结果 `OK 0 failed`，包含完整文章 100 分且不受模型高严重度问题影响、空内容 0 分、美图内部链接不进分母、短标题扣分原因、历史标签串拆分。

真实分析示例（文章 1017，评分 84）：标题 20/20，描述 20/20，完整性 20/20，关键词 15/15，标签 0/10（标签为空），ALT 不适用，内部链接 1/5（正文无链接）。已检查 76/90，换算 84。旧分析记录不按新规则重算。

## 3. Metatag 真实写入

已验证。全部发生在 Docker MariaDB `127.0.0.1:3307`，不是生产库。

站点没有节点级 Metatag 字段。前台标题和描述来自默认 token：

| 类型 | title | description |
| --- | --- | --- |
| 文章 | `[node:title] \| [site:name]` | `[node:field_summary] [node:title] - [node:field_categories:entity:name]` |
| 美图 | 同上 | 同上 |
| 基础页 | 同上 | `[node:title] - DcLili` |
| 视频 | 同上 | `[node:title] - [node:field_categories:entity:name]` |

因此写入文章标题和 `field_summary` 会改变前台 `<title>` 和 meta description。基础页和视频的 description 不读简介；只改简介不会改变这两类的 meta description。关键词建议不写入。
