## 判断顺序

`DownloadGate::decide()` 不返回 URL。顺序是：

1. 未登录拒绝。
2. 文件实体不存在则 404。
3. 不是私有地址则拒绝。这个入口不拿来读本地公开图。
4. 内容不在磁盘或远程对象上则 404。远程对象不因为 `realpath()` 失败而被当成缺失。
5. 没有挂到节点上时，只有管理员可以通过。
6. 节点不可见则拒绝。
7. 节点字段名包含 `vip` 且值为真时，要求 VIP 或管理员。
8. 配置了大于 0 的每日上限时，按 `xedc_storage_download_log` 里当天 `allowed` 行计数。
9. `private://` 且私有接管未开：返回 503，明确不签名。
10. `s3://` 且 Runtime 未开：返回 503。

通过后 `ProtectedDownloader` 才生成短时签名，并检查签名主机属于当前 Endpoint。MIME 使用 `BootGuard::contentType()`。

2026-11-02 用临时账号测了现有 `DownloadAccess`，测完已删除用户、VIP 记录、下载资源和未公开转公开的测试图片内容。

| 身份 | CLI 结果 |
| --- | --- |
| 匿名 | 403，没有 URL。匿名 HTTP 请求 `/xedc/storage/protected/1` 也是 403 |
| 普通会员 | 403，提示这是 VIP 专属资源 |
| 有效 VIP | 503，私有接管未开，没有签名 |
| 管理员但没有 VIP 记录 | 403，按普通会员拒绝，没有签名 |

判断先走下载资源的 `access_level`，再决定要不要签名。每日上限仍是 0，没有新加配额。`private://xedc-downloads` 曾是 root 所有，网站进程不能写入，现已交给 `www-data`。这不是浏览器里的会员中心点击。

## 不能做的事

私有文件不能放到 `s3fs-public/`。页面不能输出私有对象的永久 CDN URL。`DeliveryUrl` 对私有和临时地址的 `permanent` 和 `cdn` 都是 false。只隐藏按钮不算权限。

签名 TTL 来自配置 `presign_ttl`，默认 120 秒。过期后的 URL 本次没有拿真实时钟去请求一次，所以“签名过期”还没有真实 R2 测试。
