## 与缩略图的关系

图片样式读取现在不依赖存储模式：

- 对象在 R2：HEAD 校正元数据后读取 R2，派生文件写本地。
- 对象不在 R2 但本地有原图：只读本地原图，派生文件写本地。
- 样式 URL 仍是本站 `/sites/default/files/styles/...`，不是 CDN。

因此图片样式不要求先把存储切回本地才能显示。
