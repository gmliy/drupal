# 会员互动与下载权益

日期：2026-11-02

点赞、下载、分享和 VIP 做在现有模块 `xedc_core` 里，会员中心入口做在 `xedc_member`。收藏仍用原来的 `xedc_member_favorite`，没有第二套收藏表。没有支付接口，也没有改 Cloudflare R2、S3 File System 或任何第三方模块源码。

后台入口是 **会员与互动**，地址 `/admin/xedc/vip`。

## 会员等级

| 等级 | 条件 |
| --- | --- |
| 游客 | 未登录 |
| 普通会员 | 已登录，且没有有效 VIP |
| VIP | `xedc_vip` 中状态有效，并且当前时间落在开始时间和到期时间之间 |

VIP 不是永久角色。角色 `vip` 只是镜像，真正判断在每次访问时读取有效期。到期或管理员取消后，下一次权限检查立即失效，不等定时任务。定时任务只负责把过期记录标成失效、清理过期 ZIP 缓存。

管理员在 `/admin/xedc/vip` 按用户名选择会员，可以：

- 开通或重设有效期：7 天、30 天、90 天、365 天，或自定义起止时间。
- 延长：在当前到期时间之后再加一段。已经过期的，从现在起算。
- 取消：立即失去 VIP。点赞、收藏和下载历史保留。

前台标识：有效 VIP 为金色「VIP」，其余登录用户为「普通会员」。过期后显示普通会员。

会员中心 `/member/membership` 显示当前等级、开通时间、到期时间、剩余天数和权益说明。这里不能在线支付。

## 点赞

图片、视频、文章详情页有点赞按钮。已登录用户点击切换点赞和取消，数量马上更新，刷新后状态还在。游客点击会打开登录框。用户身份只取自当前会话，不接受前端提交的用户 ID。

同一用户对同一内容只能有一条记录，数据库有唯一约束。内容或用户删除时，对应点赞会清掉。

会员中心 `/member/likes` 可按图片、视频、文章筛选，分页，并取消点赞。内容已删除时该行安全跳过。

## 下载资源

一个内容可以有多个下载资源，每个资源单独设置来源和权限。实体是 `xedc_download`。在内容编辑页或后台「下载资源」里维护。

来源只能选一种：

| 来源 | 说明 |
| --- | --- |
| 上传文件 | 存在 `private://xedc-downloads/`。允许 zip、jpg、jpeg、png、webp、gif、mp4、pdf、txt |
| 外部链接 | 只允许 `http` 和 `https`。拒绝 `javascript:`、账号密码和其他协议 |
| 图片原图 | 只用于图片。取媒体源文件，不用 WebP 或图片样式 |
| 图片整组 ZIP | 只用于图片。把该内容的全部原图打成 ZIP |

权限：

| 权限 | 谁可以下载 |
| --- | --- |
| 公开下载 | 能看这篇内容的人，包括游客 |
| 登录会员 | 已登录用户 |
| VIP 专属 | 当前有效的 VIP。管理员也不会因为后台权限而绕过 |

VIP 资源不能保存永久外链。外链一旦交给浏览器就收不回，所以 VIP 必须用私有上传、原图下载路由或 ZIP 路由。

前台没有资源时不显示下载按钮。有资源时打开下载面板：电脑是对话框，手机是底部抽屉。列表显示名称、格式、大小、权限。没有权限时按钮不带真实地址，并说明当前等级。公开外链的页面 HTML 里也不写原始 URL，点击后由 `/xedc/download/{资源}` 在服务器检查权限，再 302 跳转。

直接访问 `/system/files/xedc-downloads/`、`xedc-zips/`、`xedc-download-tmp/` 会被拒绝。下载记录在服务器完成授权并开始交付时写入，状态是「已授权」，不表示浏览器已经收完文件。记录里不保存外部链接和令牌。

整组 ZIP 小于 256MB 且不超过 80 张时同步生成。更大的进入队列 `xedc_download_zip`，接口返回 202。临时包放在私有目录，约 6 小时后清理。重名文件会自动加序号。

图片原图如果本身在公开图库里，读者仍可能从图片页保存。不能外传的文件应使用私有上传，不要只配「图片原图」。

## 分享

分享面板提供：

- 当前标题和规范 URL。
- 复制链接。成功后显示「已复制链接」。
- 服务端生成的 SVG 二维码，地址 `/xedc/share/{node}/qr`。
- 浏览器支持时显示「系统分享」。无头浏览器和旧浏览器不显示这个按钮。

打开面板记为意向，不算成功分享。复制成功和调用系统分享才记成功。同一内容、同一方式、同一用户在一小时内不重复记。匿名用户用加盐的会话哈希，不记录 IP。

## 详情页操作栏

图片、视频、文章详情页共用一套操作栏。

电脑：收藏在左，点赞、下载、分享在右，按钮高度一致。图片页先是「分类 + 人物」一行，再是标签一行，然后是操作栏。

手机：四个操作同一行、等宽。图标在上，文字一行。点赞数跟在「点赞」旁边。没有下载资源时只显示其余三个，仍然均分，不出现横向滚动。

## 后台

`/admin/xedc/vip` 上的标签：

- VIP 会员
- 下载资源
- 点赞统计
- 下载统计
- 分享统计

权限：

| 权限 | 作用 |
| --- | --- |
| 管理 VIP 会员 `administer xedc vip` | 开通、延长、取消，查看记录 |
| 管理下载资源 `administer xedc downloads` | 创建、修改、停用、删除资源。不能用来绕过 VIP 下载 |
| 查看互动统计 `view xedc engagement statistics` | 只看点赞、下载、分享统计 |

这三项都限制访问，没有默认发给内容编辑和普通会员。Drupal 的超级管理员角色会因为 `is_admin` 自动拥有。

## 数据

更新钩子 `xedc_core_update_10006` 已安装这些结构：

- `xedc_like`：用户、实体类型、实体 ID、时间。同一用户对同一内容唯一。
- `xedc_vip`、`xedc_vip_log`：当前 VIP 和操作记录。
- `xedc_share`：内容、方式、结果、用户或匿名哈希、时间。
- `xedc_download_log`：授权交付记录。
- 实体 `xedc_download`：资源本身。

点赞数量按内容缓存，标签是 `xedc_like:node:{nid}`。操作栏按当前用户单独生成，不把一个人的点赞或 VIP 状态缓存给别人。VIP 缓存最长不超过到期前的剩余时间，并且不超过 5 分钟。
