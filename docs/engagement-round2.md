# 会员互动第二轮修复说明

日期：2026-11-02

站点：https://gitxx.xyz

这一轮没有新做一套点赞、下载或收藏。改动都在 `xedc_core`、`xedc_member` 和前台主题 `xedc` 里。第一轮的功能说明仍在 [engagement-membership-downloads.md](engagement-membership-downloads.md)。下面只写第二轮改过、并且和实际行为有关的部分。

## 点赞

图片、视频、文章详情页的点赞按钮对游客也是可点的，没有使用 `disabled`。

游客点击后马上提示「请先登录后再点赞。」，并打开现有登录框。这个过程不向点赞接口发请求，也不会写入记录。直接伪造 POST 时，服务器按当前会话识别身份，未登录返回 401。

登录用户点击后，按钮和数量立刻变化，再异步提交。成功后用服务器返回的状态和数量确认。失败、未登录或网络错误时，按钮和数量退回点击前。请求还没回来时，重复点击不会再次提交，页面上的其他按钮不受影响。

数据仍在 `xedc_like`。同一用户对同一内容仍只有一条记录。

| 字段 | 含义 |
| --- | --- |
| `status = 1` | 当前有效。只有这些记录计入点赞数 |
| `status = 0` | 已取消。保留记录，但不计入点赞数 |
| `changed` | 最近一次点赞或取消的时间 |

再点一次会把已取消的记录重新变成有效，不会新增第二条。内容或用户删除时，对应记录仍会删掉。

会员中心 `/member/likes` 只列出有效点赞。每条显示封面、标题、类型和点赞时间，可以进入内容，也可以取消。取消使用当前登录用户，不能替别人取消。

## 下载面板

电脑上是对话框，手机上从底部弹出，高度不超过屏幕，列表可以滚动，并留出底部安全区。ESC 和关闭按钮都可以关掉。

每个资源显示：

- 名称
- 格式和大小
- 来源：上传文件、外部链接、原图、整组 ZIP
- 权限：公开下载、登录会员、VIP 专属

没有权限时不放真实地址，并说明原因。VIP 资源不能只靠隐藏链接。

整组 ZIP 不会一点就跳走。页面先请求状态：

| 状态 | 用户看到的结果 |
| --- | --- |
| 可以生成或已经准备好 | 开始下载 |
| 排队或正在生成 | 留在面板里，提示稍后再次获取 |
| 权限不足、文件不存在或生成失败 | 留在面板里，显示具体原因 |

## 整组 ZIP

压缩包使用图片原图，不使用图片样式和 WebP 衍生图，也不只打包封面。空文件和无效引用会跳过。重名文件按 `image.jpg`、`image_2.jpg`、`image_3.jpg` 放入压缩包，包内不写服务器绝对路径。

读取走 Drupal 文件接口。文件在本地时直接读真实路径；不在本地时复制到临时文件再打包。这一轮站点上的原图都在 `public://`，R2 没有实测。

小于 256MB 且不超过 80 张时同步生成。任一条件超出后进入队列 `xedc_download_zip`，不能假装已经完成。队列由现有 Cron 执行，每 15 分钟以 `www-data` 运行。完成后状态写成「已生成」。

ZIP 放在 `private://xedc-zips/`。这次修好的直接原因是该目录原来属于 root，网站进程无法创建 ZipArchive 需要的临时文件，所以页面约 105ms 就返回 500。更新后目录属于 `www-data`，权限 `0775`。父目录仍是私有目录，其他系统用户不能进入。

下载地址每次都重新检查权限。VIP 到期或被取消后，原来的地址立即拒绝。临时包大约 6 小时后清理。任何一张原图读不出来，就删除未完成的包，并把任务记为失败。

图片节点 315 的 4 张本地原图实测：HTTP 200，约 0.8 秒，16,743,233 字节，文件头为 ZIP，4 个 PNG 都能解压。

超过 80 张和超过 256MB 的队列没有造测试文件，未测。

## 下载记录

仍用 `xedc_download_log`。新增字段只补充信息，不覆盖旧行：

| 字段 | 含义 |
| --- | --- |
| `source` | 原图、整组 ZIP、上传文件或外部链接 |
| `tier` | 下载当时的等级：游客、普通会员、VIP |
| `delivery` | 交付方式，例如文件或 ZIP |
| `detail` | 失败或排队时的简短说明 |

后台把结果写成下面几种，不把「已授权」写成「浏览器已经收完」：

- 已授权
- ZIP 生成中
- ZIP 生成失败
- 交付失败

会员中心 `/member/downloads` 显示封面、标题、资源名、格式、大小、时间和上述状态。

## 分享

分享框标题是「分享内容」。里面有当前内容标题、规范 URL、复制按钮和二维码。浏览器支持系统分享时才显示系统分享。

打开面板只记分享意向。复制成功和系统分享调用成功另记。不能据此认为已经发到社交平台。无头浏览器没有系统分享能力，按钮会隐藏，这不是站点故障。

## 后台菜单

左侧导航不是 Drupal 的「人员」菜单。现有「用户管理」定义在 `xedc_admin` 主题的 `_xedc_admin_navigation_definitions()`，机器名是 `users`。

「会员与互动」加在这个组的最后，排在「会员管理」和「内容审核」后面。地址仍是 `/admin/xedc/vip`。图标用现有的 `users`。原来挂在 `system.admin` 上的一级菜单项已停用，避免左侧再出现一个同名顶级项。

菜单是否显示，跟路由权限一致：能访问 `/admin/xedc/vip` 的人才看得到。没有这个权限时，直接打开地址会拒绝，不靠藏菜单来保护。

## 后台

入口仍是 `/admin/xedc/vip`。权限没有扩大：

| 权限 | 作用 |
| --- | --- |
| `administer xedc vip` | 开通、延长、取消 VIP |
| `administer xedc downloads` | 管理下载资源，并可把失败的 ZIP 重新排队 |
| `view xedc engagement statistics` | 查看互动统计 |

标签：

1. VIP 会员
2. 下载资源
3. 互动总览：有效点赞、已授权下载、成功分享、有效 VIP、近 7 天和热门内容
4. 点赞明细：内容、类型、节点 ID、会员、UID、时间和有效或已取消
5. 下载明细：内容、资源、来源、用户、当时等级、时间和结果
6. 分享统计：意向和成功分开
7. ZIP 任务：等待、生成中、已完成、失败和原因

点赞明细可以按类型、标题、用户、日期和状态筛选，并按时间或内容点赞数排序。标题按节点现查，不把标题当作唯一关联。内容删除后显示「内容已删除」。有「管理内容」权限时才出现编辑链接。

ZIP 重试只重新排队，不会把任务直接标成完成。

列表每页 40 条。内容标题和用户名在查询里批量取出。

## 数据变更

更新钩子 `xedc_core_update_10008` 已执行：

- `xedc_like` 增加 `status`、`changed`。旧记录默认为有效，时间回填为原来的点赞时间。
- `xedc_download_log` 增加 `source`、`tier`、`delivery`、`detail`。旧记录这些字段为空。
- 新建 `xedc_zip_job`。一个资源只保留最近一次状态。

没有删除原有点赞和下载记录，也没有新建第二套点赞表或下载日志。没有自动回滚钩子。若要撤回，应再写更新钩子删除这些新增字段和新表，不要手工删业务数据。
