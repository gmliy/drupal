## 没有完成的部分

- 不能按文件类型把新文件写到不同供应商。
- Amazon S3、阿里云 OSS、腾讯云 COS、Backblaze B2 不能连接。
- 迁移没有升级成任意已实现供应商之间的任务执行器。
- 没有做写入探针。
- 新权限还没有绑定到路由。

## 生产环境结论

验收结束时的 PHP-FPM 请求使用 R2 公开包装器和本地私有包装器，CDN 开启，Private takeover 关闭。这个结果来自 PHP-FPM 编译出的容器和公开页面上的 CDN 地址，不是只看 CLI。

没有修改 `config/sync`。没有修改五个环境变量的值。没有新的数据库 schema。
