# AI 运营中心验收说明

本文说明 2026-11-02 对 `xedc_ai` 的验收结果：现在能用到什么程度、改了什么、哪些结果不能当成已经完成。逐项数据和调用记录见 `docs/XEDC_AI_FULL_ACCEPTANCE_REPORT.md`。日常操作见 `docs/ai-operations-center.md`，密钥保存见 `docs/ai-api-key-storage.md`。

结论：**可以有限试运行**。自动审核保持关闭。

## 2. 这次实际验证了什么

真实 DeepSeek 调用只做了少量短文本请求。文章、图片、视频各完成一次文字审核，另有一次 SEO 建议和一次指定中文短文本。图片文件和视频文件没有发给模型，也没有抽帧。

已确认：

- 连接可以成功，返回内容非空，Token 写入 `xedc_ai_usage`。
- 审核 JSON 含状态、风险和摘要。本地规则单独保存在 `local_checks`，不会因为 AI 返回正常就被丢掉。
- 测试内容保持未发布。
- 相同测试图片的 SHA-256 一致，不同图片的 pHash 距离大于 10。视频只做 SHA-256。重复页没有删除、合并或替换文件。
- 会员投稿列表能看到最新的 `needs_review` 修订。未确认不会改状态。退回变成 `changes_requested`，拒绝变成 `rejected`，两者都不发布。拒绝时必须填写原因。
- 暂停后任务不会调用模型。预算临时改为 0 时，自动和手动调用都会被拒绝；恢复原预算后手动调用允许。
- 用户 1 可以打开 `/admin/xedc/ai` 下的页面。内容编辑、普通会员和匿名用户不能打开。内容编辑角色没有 AI 权限。
- 模拟脚本 `vendor/bin/drush php:script web/modules/custom/xedc_ai/tests/manual/ai-self-test.php` 为 158 通过、0 失败。它使用模拟 HTTP，不能代替上面的真实调用。

已入库费用按当前单价合计 0.049817 元。另有三次探测没有写入用量表，按同一单价估算约 0.005193 元。全部真实调用约 0.055 元。这不是厂商账单。

## 3. 验收中改过的地方

### 输出上限

800 个完成 Token 不够。文章、图片、视频和 SEO 的第一次真实调用都正好用满 800，JSON 被截断，审核不能完成。

已把供应商 `deepseek` 的输出上限和活动配置 `xedc_ai.settings:max_tokens` 改为 4096。新供应商表单和安装默认值也改为 4096。复测后四类请求都完成：文章 1126、图片 1505、视频 1825、SEO 2371 个完成 Token。指定短文本为 2406，JSON 可以解析。

数据表字段的默认值仍是 800。正常从表单保存供应商时会写入 4096，不受这个字段默认值影响。`config/sync` 没有改。

### 投稿列表

最新待审核修订的 `revision_translation_affected` 可以是空的。旧查询要求这个字段为 1，于是看到的是更早的草稿，列表里就没有这篇投稿。

现已按节点和语言取最大修订号。临时投稿复测可以出现在列表中，测试稿随后已删除。原生 `/admin/content/moderated` 没有改。

### 测试连接的费用

以前测试连接不带模型单价，成功后也显示费用未核算。现在会读取同供应商、同模型名的启用单价。用量 141 为 33 输入 Token、9 输出 Token，费用 0.000036 元，与 `0.02 / 4` 的计算一致。

### 自测断言

生产环境已经有调用记录，概览不会显示“还没有调用记录”。自测已改为同时接受空状态和已有调用。这只改测试，不改页面。

## 4. 不能当成已经完成的部分

- **SEO 写入只有标题和简介。** 管理员确认后，建议标题写入节点标题，Meta Description 写入 `field_summary`。它不会写入 Metatag。标签、分类、ALT、关键词和结构建议只生成，不落库。没有简介字段的视频会拒绝写入简介。未确认的建议不会自动写入。
- **重复页只显示文件。** 完全相同的文件显示编号和文件名，相近图片显示 pHash 距离。页面不显示使用这些文件的内容。
- **缓存 Token 没有单独计价。** DeepSeek 响应里有 `prompt_cache_hit_tokens` 和 `prompt_cache_miss_tokens`。客户端只统计 `prompt_tokens` 和 `completion_tokens`。如果缓存命中更便宜，页面费用会高于实际账单。
- **单价还没有核对。** 当前是输入 0.02 元、输出 4 元 / 百万 Token。输出是输入的 200 倍。验收没有改这个数。
- **通过投稿没有实际保存。** 工作流里存在 `needs_review` 到 `published`。真正保存会发布内容，并可能调用 `xedc_auto_translate` 的外部翻译，所以没有执行。
- **翻译建议没有调用模型。** 只验证了入队和取消。取消后没有新增译文，也没有触发 DeepL。
- **没有跑全站 cron，也没有在浏览器里点击。** 页面是以用户 1 在服务器上渲染的。队列工人已注册，但不能据此说 cron 已经处理过生产队列。

五个任务没有各自指定模型。需要分开时，在运行配置里选择，不要依赖模型能力字段自动分配。

## 5. 试运行时建议遵守的边界

- 保持四个自动审核开关关闭。
- 只对草稿或临时内容手动审核。不要对真实稿件做全站批量审核。
- 不要为了测试关闭权限、表单令牌或密钥文件权限。
- SEO 确认前先看清：简介字段会变成 Meta Description 的内容。
- 通过会员投稿前确认可以接受发布，以及随之可能发生的翻译请求。
- 内容编辑目前不能进入 AI 运营中心。要开放给编辑时再单独授权，不要把 API Key 管理权限授给普通编辑。
- 用量 141–145、146–149 和 164 是这次验收留下的真实调用，不要当垃圾数据删除。142–145 是输出被截断的那几次，调用成功，但当时的审核结果没有完成。

测试用户和标题带 `[XEDC-AI-TEST]` 的测试内容已经删除。验收结束时这两类计数都是 0。
