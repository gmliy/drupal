## 播放器

底层保留 Plyr。`plyr.min.js` 里没有版本号。控制栏有播放、进度、速度、音量、全屏。没有多码率，所以没有清晰度按钮。没有字幕轨，也不为字幕加库。HLS 只处理 `.m3u8`。没有 DASH。

封面存在，`preload` 为 `none`。Chromium 156 在 1280 宽打开 nid 116：`play()` 后在播放，`pause()` 后暂停，按 `M` 可以静音。390 宽时控制栏右缘在 346，没有横向溢出。

`currentTime` 停在 0。倍速设成 1.5 后仍是 1，进度和倍速的本地存储是空的。第二次无头测试停在等待媒体元数据，进程被终止，那次结果没有采用。

## 时长

系统里已有 `/usr/bin/ffprobe` 6.1.1，没有再安装。检测放进队列 `xedc_video_duration`，不在前台请求里执行，也不把整个文件读进 PHP。该版本不接受 `-nostdin`，去掉这个参数后补齐可以完成。

格式是同一套：5 秒为 `00:05`，65 秒为 `01:05`，542 秒为 `09:02`，3661 秒为 `01:01:01`。没有超过一小时的真实视频，3661 只在格式函数里测过。

统计命令 `drush xedc:video-duration-stats`：

| 项 | 数量 |
| --- | ---: |
| 视频总数 | 8 |
| 已有时长 | 7 |
| 缺失 | 1 |
| 文件不存在 | 1 |
| 无法读取 | 1 |
| 已记录失败 | 2 |

失败原因：nid 9 是 `video file is missing`，nid 55 是 `remote address was not downloaded`。已有正时长的视频默认跳过。游标跑完再执行，处理数是 0。

播放进度没有新表。会员接口是 `/video/progress/{node}`，游客用浏览器本地存储。这次没有登录，也没有把播放时间推过 5 秒，所以续播没有测到。

播放量仍是 Statistics 的页面计数，播放器初始化不另记一次。视频页加了 30 分钟内不重复计数的脚本，但没有在刷新前后对照 `node_counter`。
