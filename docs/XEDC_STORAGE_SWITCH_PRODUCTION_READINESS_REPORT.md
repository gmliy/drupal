## 风险

1. 切回本地时，2 个只在 R2 的文件（约 4.6MB）必须先复制到本地，否则对应内容会缺原图。
2. 再次切到 R2 不会自动补上 5 个只在本地的 PNG。它们的缩略图现在靠本地只读回退，原图 URL 仍会指向 CDN，而 CDN 上没有这 5 个对象。
3. 全量 SHA-256 还没做。大小一致不能代替内容一致。
4. 正式切换的失败回滚没有在生产状态上演练。隔离测试不能代替那一步。
5. Cloudflare 上仍有 4 个旧样式 URL 的 HTML 404 缓存。这不阻塞存储切换，但清理前直接访问旧地址会看到 404。

## 进入切换前必须另行完成

1. 管理员单独授权。
2. 对 128 个两边都有的文件做流式 SHA-256，并处理不一致项。
3. 明确 5 个本地独有和 2 个 R2 独有文件的处理方式。未授权前不要复制或删除。
4. 在维护窗口执行切换，并保留当前 `active.json` 的回滚副本。
5. 切换失败时只恢复运行状态，不删除任何一侧的正式文件。

在这些完成之前，不建议进入生产切换阶段。
